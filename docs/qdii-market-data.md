# 场内标普 / 纳指 QDII 数据

## 目标与范围

本地维护沪深上市标准标普500 / 纳斯达克100 QDII 的每日单位净值、未复权开高低收价和折溢价，供 agent 计算区间价格/净值变化与后续理财分析读取；本地页面仅展示两个指数的区间价格收益率与折溢价，共四张图，不展示明细表格或导出按钮。ETF 与 LOF 均纳入，仅跟踪标准市值加权的标普500与纳斯达克100。排除行业、科技子指数、等权重及其他变体；不将两个标准指数视为可互换标的。

目录来源为东方财富基金目录与基金档案：名称含“标普”“纳斯达克”“纳指”，基金类型为海外股票或 QDII，代码为沪深基金范围，并由档案全称确认 ETF / LOF 身份；历史场内行情作为进一步验证。仅接纳档案“跟踪标的”明确对应上述两个标准指数的产品；未知或其他指数不会按名称猜测纳入。每次更新重新发现产品，保留历史目录，新增产品自动回补。范围完整性依赖上游分类、命名与档案；QDII活跃目录不包含名称不体现这些关键词的主动基金、场外份额、境外直接上市产品；VOO、QQQ以独立境外参考数据提供，仅用于表格对照。历史已退市且已从上游名单移除的产品不承诺全量发现。

## 方案与约束

- Python 标准库 + SQLite；不引入 Web 框架或前端构建工具
- 行情数据独立于个人持仓，存入 `data/processed/qdii/market.sqlite3`
- 原始公开响应按采集批次只新增归档到 `raw/market/qdii/`；不混入持仓或交易目录。后续批次附请求 URL、时间、SHA-256 元数据；首次回补批次可按脚本与响应名追溯
- 行情优先请求东方财富，连接失败或响应无效时切换腾讯未复权日线，并逐页向前回补；腾讯不提供历史成交额时留空，绝不使用成交量代替成交额
- 日K使用真实开高低收价（OHLC），检查低价≤开/收≤高价；历史OHLC从对应原始响应补入，并核对代码、日期、收盘价与来源批次，不用单个收盘价伪造蜡烛。旧库首次升级新增open/high/low列，未知字段留空
- 每只基金净值、行情全部通过校验后，以单个事务更新；失败保留上次数据并记录错误，命令以非零状态退出
- 同一代码 / 日期幂等更新，净值修订保留在原始响应中；每条数据保存首次观察时间、最近观察时间和来源批次
- 净值每次重新读取；已采集当日收盘价时复用本地价格，仍刷新净值。新交易日的价格增量覆盖最近14个日历日；新基金回补全部可获取历史，`update --full-history` 可强制复查全部历史价格
- 同一上游主机的请求默认至少间隔1秒；401、403、429、501不在同一请求内密集重试，批次失败保留旧数据。腾讯备源实际出现过WAF限流，自动更新不能保证每次成功，应检查页面更新状态
- 本地服务仅监听 `127.0.0.1`，白名单提供页面与行情 API，不暴露项目根目录

## 交易日更新规则

2026-11-03 用户确认：非交易日不采集对应市场数据，沿用上个交易日数据及实际日期。A股行情、净值和市值按上海当地日期判断，VOO / QQQ及配套汇率按纽约当地日期判断；两个市场独立执行，一个市场休市不阻止另一个市场更新。周末及交易所公布的节假日均跳过，调休周末不视为A股交易日；美股提前收盘日仍为交易日。

日历维护在 `config/qdii_trading_calendar.json`，目前覆盖2026年，来源为[上交所年度休市公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)与[NYSE休市日历](https://www.nyse.com/trade/hours-calendars)。新年度运行前须补充对应年份；未覆盖年份明确报错，不按普通工作日猜测。无需新增依赖或在休市日联网查询日历。

每日20:30任务仍会唤醒，但休市市场在任何请求、原始归档及快照写入前返回，记录跳过日志，不覆盖最近成功状态。此规则同样适用于手动 `update`（包括 `--full-history`）、`update-sizes` 和 `update-references`。网页“重新读取”继续只读取本地数据，保留实际行情日期；美股尚未收盘时参考收益按已有最近完整日线展示。

## 折溢价口径

1. `premium_same_date_pct`：交易日收盘价乘适用的份额拆分换算因子，再除以同估值日单位净值，减1后乘100。无单位错位时因子为1；净值未公布则为空，不用前值代替。中美交易时差使此值属于事后比较。`premium_price_factor` 记录实际使用的因子；原始收盘价与 OHLC 不修改。
2. `premium_previous_nav_pct`：交易日收盘价 ÷ 严格早于交易日的最近估值日净值 − 1，乘100。保留 `previous_nav_date` 与间隔天数；它不保证当时已公布，名称明确为“此前净值参考溢价（重建）”。
3. 不回填、不伪造历史 IOPV。每日变化为同口径相邻有效交易记录之差，单位为百分点；缺失日不跨日伪装成单日变化。
4. 净值使用单位净值，不使用累计净值；原始价格保存未复权值。折溢价遇到分红、拆分等公司行动时，需结合公告把价格和净值换算到相同单位。
5. `first_seen_at` 是本系统首次观察时间，不是基金公布时间。历史数据不能直接用于当时可得信息的策略回测。

### 已核实的份额拆分修正

- 广发纳指ETF（159941）于2022-07-04按1:4拆分，拆分后首个交易日为7月5日；博时标普500ETF（513500）于2022-03-29按1:2拆分，拆分后首个交易日为3月30日；国泰纳指ETF（513100）于2022-01-13按1:5拆分，拆分后首个交易日为1月14日。
- 这些日期和倍数由脚本中的 `SHARE_SPLITS` 维护。区间收益率将拆分前收盘价换算到拆分后份额单位，避免产生虚假的大幅亏损；原始收盘价与 OHLC 不修改。
- 广发纳指ETF的2022-07-04同日溢价使用拆分后单位净值，因此也需将该日拆分前收盘价乘0.25；此前净值参考溢价仍使用原始收盘价。修正后同日溢价约-0.53%，而非约297.86%。JSON/API历史提供 `premium_price_factor` 和 `return_price_factor` 供核对。

## 使用与每日维护

无需新增依赖，在项目根目录执行：

```bash
python3 scripts/qdii_market.py update
python3 scripts/qdii_market.py serve --port 8876
```

页面：`http://127.0.0.1:8876`。保留四张图并新增标的评分表：标普500区间收益率、标普500溢价率、纳斯达克100区间收益率、纳斯达克100溢价率。时间范围支持近1月、近3月、近6月、近1年、近3年、近5年、近10年和全部历史。每组标的的勾选同时影响该组两张图，支持逐个选择/取消、全选/取消全选，无5只上限。两组均默认勾选评分≥50分的标的，无评分不默认勾选。评分表下、勾选列表前提供全选/取消全选和最低评分输入框（0–100整数），两组门槛独立且本机保存；2026-11-02 更新时将此前保存的门槛一次性重置为50分，后续手动设置继续保存；每次输入有效整数门槛时立即重新选择对应指数，不影响另一组，之后仍可手动调整。勾选列表按评分降序排列，同分按代码升序，无评分放末尾。每次打开或刷新页面按已保存的评分门槛重新筛选，不恢复上次手动勾选；本机只保存门槛、时间范围和溢价口径。同一页面内重新读取数据保留当前手动勾选。

区间收益率按拆分调整后的收盘价计算，每只基金以所选区间内首个有效交易日为0%；上市较晚的标的起点会晚于区间起始日。该价格收益率不计现金分红。溢价在净值未公布时留空，不跨缺失值连线。页面保留四图，并增加每个指数内的标的评分表；无导出入口。

已有日线缺少OHLC时，可离线从历史原件补齐（不联网、不修改原件）：

```bash
python3 scripts/qdii_market.py backfill-ohlc
```


完整数据库含 `funds`、`prices`、`navs`、`runs`，主键分别为代码或代码+日期。`prices.open/high/low/close` 为未复权开高低收价格，`prices.price_source` 区分 `eastmoney` / `tencent`；`source_run` 对应原始响应批次目录。独立 `navs` 保留没有场内行情日的净值。后续分析可直接读 SQLite，也可导出 JSON（包括完整净值历史与逐日溢价）：

```bash
python3 scripts/qdii_market.py export
```

默认 JSON 输出 `data/processed/qdii/market.json`。Agent 使用 SQLite、JSON导出或只读 `/api/data` 读取具体数值，不从图表坐标或悬浮提示反推。区间价格变化使用实际起止收盘价，区间净值变化使用实际估值日；分红、拆分、费率与个人资金流需另行结合事实处理，单纯价格/净值变化不等同于个人投资收益。网页选择只是展示偏好，不改变agent可读取的18只产品明细。数据动态读取 SQLite；页面“重新读取”不访问外部数据源，不启动采集。读库时使用一致性快照，更新期间不会混读同一基金半个事务。

macOS 定时更新安装：

```bash
python3 scripts/qdii_market.py install-schedule
```

已在本机安装 `~/Library/LaunchAgents/local.finance.qdii-update.plist`，登录会话内每天 20:30 运行一次，更新已披露净值与已收盘价格。电脑关机、未登录或网络不可用时不能保证当次执行，恢复后可手工 `update`。采集时不保证当日净值已经公布，页面保留实际净值日期。日志：`data/processed/qdii/update.log`、`update-error.log`。失败不会覆盖旧行情或净值，可重复运行补采。

停止每日更新：

```bash
launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/local.finance.qdii-update.plist
```

删除该 plist 可防止下次登录加载；如需重新安装，先删除停止后的 plist 再运行安装命令。网页后台服务独立于每日采集任务，安装或重新加载：

```bash
python3 scripts/qdii_market.py install-service --port 8876
```

本机已安装 `~/Library/LaunchAgents/local.finance.qdii-web.plist`。登录后自动启动，进程退出后自动重启，关闭终端或浏览器不影响服务。电脑开机且用户已登录时访问 `http://127.0.0.1:8876`；关机或睡眠期间无法访问。仅监听本机地址。日志为 `data/processed/qdii/web.log`、`web-error.log`。后台服务不自动采集数据，继续由独立的每日20:30任务更新。

停止网页服务：

```bash
launchctl bootout gui/$(id -u)/local.finance.qdii-web
```

停止后删除对应 plist 可取消下次登录启动；再次执行 `install-service` 可恢复。调试时可先停止后台服务，再用 `serve --port 8876` 前台运行，避免端口冲突。

配置位于 `config/qdii_market.json`：请求超时默认25秒，每个请求最多3次尝试，退避1秒、2秒，并发4个带名称的采集线程，同一主机请求至少间隔1秒。指数身份只取基金档案“跟踪标的”，不以代码映射或名称猜测补入未知产品。配置文件不存在时使用相同网络默认值；格式错误直接失败，不静默使用另一套配置。

## 标的简单评分

2026-10-29 新增同指数内的百分位评分，满分100。5/3/1年累计持有收益分别占35/25/20%，总市值10%，同日净值溢价10%；收益与市值越高越好，溢价越低越好，并列取平均排名，单个样本记50分。收益使用拆分调整价格，现金分红默认再投资，起点取周年日或此前最近交易日（最多7天），终点统一为行情基准日。历史不足完整年限不以成立以来收益补充。

各指标只在同一指数内比较，各自统一日期并分别显示；缺失对应日期数据时留空。缺失项剔除后归一权重，可用指标不同的评分不宜直接等同。表格在评分后展示总市值（亿元），不展示覆盖率。评分使用全部活跃标的，不随图表勾选、时间范围或溢价图口径变化。属于历史数据排序，不预测未来收益。

总市值来自腾讯单标的行情字段45（亿元转换为元），保留行情实际日期，校验代码、时间及正有限数值。`update` 在行情更新后采集市值，也可单独执行 `python3 scripts/qdii_market.py update-sizes`。原始响应及请求元信息存入独立 `_sizes` 批次，当前公开快照保存于 `data/processed/qdii/sizes.json`，通过 `/api/data` 的 `market_size` 返回。市值采集失败时该标的本批次留空并保留错误，不把旧市值用于本次评分；命令以非零状态退出。

评分中的收益默认采用现金分红再投资口径：每次分红按除息日收盘价买入，允许碎份额，新增份额参与后续分红。累计持有收益 = 期末拆分调整价格 ÷ 期初拆分调整价格 × ∏（1＋每份分红 ÷ 除息日价格）−1；每份分红与除息日价格均使用相同的拆分调整单位，区间起始日的分红不计入。缺少除息日价格时该区间收益留空。基金运作费用（管理、托管等）已反映在净值及交易价格中，不重复扣费；券商佣金及实际成交价差未知，未计入。图表继续保留原有的价格收益口径。分红事件读取最新净值原始响应的 `unitMoney`，保留可识别现金分红；已确认的拆分由既有规则处理，未知事件或来源缺失时留空收益，避免伪称完整收益。当前18只基金的可用历史源中仅发现3个已确认拆分，无现金分红事件。

实时可用性：收益截至最后完整日线，溢价采用截至该日最近有同日净值的统一日期，市值采用最新行情快照的统一日期；页面分别显示三者日期。每项指标内不混用不同日期，缺失指定日期数据的标的该项留空；较旧市值不用于评分。

本次验证：19项Python测试、7项前端行为测试通过；通过真实本地HTTP响应验证四图与18只标的评分表渲染。18只行情与市值更新成功。浏览器目视检查被自动审批拒绝，未完成目视验收。


## VOO / QQQ 境外参考行

两组评分表开头分别增加 VOO、QQQ，各展示美元、人民币两行的5/3/1年累计收益，不参与QDII评分、门槛筛选和四图。参考行市值与净值溢价尚未采集，显示 —，不填零。参考收益截至不晚于页面国内行情日期的最近可用完整美股交易日，行内标注实际日期；同一标的美元与人民币行使用相同交易日，避免每日20:30采集时美股尚未收盘导致收益全部留空。缺少该日人民币数据或周年起点（允许此前7天）时留空，不混用两种币种的截止日期。

来源为 [Yahoo Finance 历史数据](https://finance.yahoo.com/quote/VOO/history/) 的分红拆分复权收盘价（adjclose），不再次加分红；人民币行将各日复权价乘[欧洲央行日度参考汇率](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)交叉计算的USD/CNY（每欧元对应CNY ÷ 每欧元对应USD），缺日只取此前最近7天内汇率。欧洲央行通常在工作日16:00 CET左右发布，参考定价时间约14:10 CET，不称为人民币收盘汇率。收益为复权价比值减一，已包含基金运作费用，未计个人分红税、佣金、换汇价差。中美收盘存在时差，人民币参考使用公开汇率，不等同于QDII实际估值汇率。

`update` 每日任务同时更新境外参考；可单独运行：

```bash
python3 scripts/qdii_market.py update-references
```

原始公开响应与请求元信息只新增存入 `raw/market/qdii/<批次>_references/`，处理后快照为 `data/processed/qdii/references.json`（`fx_source`、`fx_latest_date`记录汇率源及实际最新日期，每条人民币历史保留`fx_date`与`usd_cny`），经 `/api/data` 和JSON导出的 `references` 提供。VOO、QQQ不进入QDII的`funds`目录或个人资产。失败批次记录错误、对应收益留空，命令非零退出；仅汇率失败时美元行仍可展示，页面行内提示失败，不冒用旧数据。首次未采集时仍保留两种币种参考行。
