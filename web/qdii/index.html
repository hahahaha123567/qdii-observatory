评分规则 · 收益优先

同指数内按各指标百分位排名计分，高收益、大市值、低溢价得分更高，并列取平均。5年 / 3年 / 1年累计持有收益权重为35% / 25% / 20%，总市值10%，同日净值溢价10%。已调整份额拆分，现金分红默认按除息日收盘价再投资，允许碎份额。基金管理费、托管费等运作费用已体现在历史净值及价格中，不重复扣减；券商佣金和买卖价差未计入。

缺失指标不计分，其余权重按比例归一；可用指标不同的评分应谨慎比较。分红来源缺失、事件无法识别或缺少除息日价格时，收益留空。溢价采用最近有同日净值的统一日期，总市值采用最新统一行情快照，实际日期见下方。收益起点取周年日或之前最近交易日（最多7天）；不足完整年限留空。评分包含全部标的，不受图表选择影响。同日溢价为事后比较，历史评分不预测未来收益。

每组表格开头提供境外参考：VOO / QQQ 各含美元与人民币两行，收益采用 Yahoo Finance 分红拆分复权价；人民币收益按欧洲央行各历史日期的人民币、美元兑欧元参考汇率交叉换算（汇率缺日最多向前取7天）。参考收益截至不晚于国内行情日期的最近完整美股交易日，实际日期见各行；美元与人民币行使用相同交易日。参考行不参与 QDII 评分与图表选择，未采集市值及净值溢价显示 —。中美收盘时差、税费与换汇成本会影响实际结果。
